# Marque « Mada-Made »

La licence [MIT](./LICENSE) couvre **le code de ce dépôt**. Elle ne couvre pas la
marque. Ce fichier énonce la règle que le projet applique à sa propre identité.

Les conditions d'utilisation du site disent déjà que la licence ne touche ni le
nom, ni le logo, ni l'identité visuelle. Ici, cette promesse devient vérifiable
dans le dépôt.

## Ce qui relève de la marque

- Le nom **Mada-Made**, et ses graphies
- Le symbole : les formes dérivées des pics du Tsingy de Bemaraha
- La signature **MADA MADE / BUILT FROM MADAGASCAR**
- La palette : noir `#000000`, zinc `#A7A9AC`, gris clair `#E5E5E5`, blanc `#FFFFFF`
- Les fichiers d'identité visuelle : `public/branding/`, `public/logos/`

## Ce qui est permis

- Citer le projet, le lister, créer un lien vers ce dépôt
- Installer et auto-héberger le code sous licence MIT, y compris à des fins commerciales
- Forker le dépôt, y contribuer, publier vos modifications
- Étudier le code et le symbole pour apprendre, sans réutiliser le symbole

## Ce qui est interdit

- Republier une version modifiée sous le nom « Mada-Made ». Le symbole identifie
  le projet, pas votre instance.
- Servir une version modifiée en laissant croire qu'elle est officielle ou
  maintenue par le projet
- Utiliser le nom ou le symbole comme marque de votre propre produit, ou d'une
  manière qui laisse croire à un lien avec le projet
- Empêcher vos propres utilisateurs d'utiliser le logiciel avec son identité
  d'origine

Une démonstration, un exposé, un article de blog ou une installation chez vous
restent libres, tant que vous ne présentez pas votre version comme le projet
lui-même.

## Demander une autorisation

Décrivez l'usage prévu et son contexte. Un usage historique, éditorial ou non
commercial est généralement accordé ; un usage commercial est étudié au cas par cas.
Écrivez à l'adresse de contact publiée sur le site.

## Deux limites de ce document

**Une politique n'est pas un enregistrement.** Ce fichier énonce une règle et
engage le projet à la tenir. La protection juridique, elle, vient d'un dépôt de
marque, qui reste à faire. D'ici là, un usage détourné se signale ; il ne se
poursuit pas encore.

**Ce n'est pas un avis juridique.** Faites valider tout usage commercial par un
conseil avant de vous en servir.

## Pourquoi cette distinction

Le projet existe parce qu'il arrive que des produits se construisent ici sans que
personne ne puisse dire qui les a faits, ni les reprendre, ni les retrouver.
C'est exactement le contraire d'une plateforme qui garde tout et ne rend rien.

Autoriser qu'on reprenne le code — c'est ce que fait la MIT — tout en refusant
qu'on porte le nom d'un autre comme si c'était le même : c'est la même idée,
appliquée à nous-mêmes.
